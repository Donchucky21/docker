# TalentBridge Job Portal Frontend

Professional React frontend for a three-tier job portal application.

## Features

- Candidate registration and login
- Protected job portal dashboard
- Browse and search job vacancies
- View job details
- Submit applications
- View applicant profile and application history
- API integration with JWT authentication

## Tech Stack

- React + Vite
- React Router
- Axios
- CSS modules via plain CSS files
- Lucide React icons

## Getting Started

```bash
cp .env.example .env
npm install
npm run dev
```

The app runs on `http://localhost:5173` by default.

## Environment Variables

```bash
VITE_API_BASE_URL=http://localhost:8000/api/v1
```
